Long Tail

The obvious answer loses. Name something real that nobody else would think of.

Or pick a category

How to play
  • Each prompt asks you to name something: an animal, a country starting with "K", a Tom Hanks movie.
  • You get 25 seconds. Type your answer and hit Enter. Hit Enter again to lock it in.
  • If time runs out while you're being asked to confirm, that answer counts.
  • The less famous your (valid) answer, the more points: Obvious 10, Too Clever 15, Common 30, Rare 60, Deep Cut 85, The Gem 100.
  • Every prompt hides one Gem. Find it for 100.
  • Reusing an answer you already played on that prompt only scores Too Clever.
  • Answers and fame come live from Wikidata (how many Wikipedias cover each thing).
